# Lego-Lager

Offline-Web-App zum Zusammensuchen von Lego-Sets aus nummerierten Kästchen.

- Sets und Teilebilder kommen von Rebrickable (eigener API-Schlüssel in den Einstellungen).
- Standorte (Kästchen → Teilenummer) kommen aus einer Google-Tabelle (Tab „Kästchen“).
- Fortschritt und Einkaufsliste liegen nur auf dem Gerät (IndexedDB); Sicherung per Export.
